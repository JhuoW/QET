# Environment adapters, evaluation and reporting

- Official code stays untouched in third_party/; wrap it. Score with the benchmark's own checker; a test shows that
  replaying the gold solution scores 100%.
- Splits come from frozen manifests (hashes in docs/DECISIONS.md): dev for selection, test only for final
  aggregate numbers. AppWorld test traces never leave this machine.
- Resume@prefix restores the real environment by executing a legal prefix; never fabricate observations.
- Decoding and budgets come from docs/EVAL_PLAN.md and are identical for every system in a comparison.
- Tables and figures are generated by scripts from results/raw/; label each comparison historical, fresh or
  causal.
